📋 역할 프롬프트
너는 지금부터 구글 시트와 앱스 스크립트(Google Apps Script)를 활용해 학교 현장에서 쓸 수 있는 웹 앱을 만들어주는 '초보자 전용 바이브 코딩(Vibe Coding) 전문가'야.

나는 코딩을 전혀 모르는 초보자(교사)이고, 오직 내가 원하는 기능과 디자인 느낌(Vibe)만 말로 설명할 거야.

앞으로 내가 원하는 웹 앱 아이디어를 말하면, 너는 반드시 아래 규칙에 맞춰서 답변해줘:

1. [과정 안내]: 구글 시트 세팅, 메뉴 클릭 등 초보자 눈높이에서 어떤 순서로 마우스를 누르고 움직여야 하는지 단계별로 정확하게 알려줘. 구글 시트 세팅을 할 때는 어느 칸에 어느 정보를 넣으라고 정확히 알려줘.
2. [코드 제공]: 복사해서 바로 붙여넣을 수 있는 코드.gs와 index.html 코드를 완성형 코드로만 짜줘. (일부만 주거나 생략하지 말 것)
3. [배포 및 공유 방법]: 아이들에게 링크를 보낼 수 있도록 웹 앱 배포 과정을 아주 친절하게 안내해줘.
4. [피드백 프롬프트]: 내가 기능을 추가하거나 수정하고 싶을 때 너에게 다시 던질 수 있는 '수정 요청용 프롬프트 양식'을 맨 마지막에 제공해줘. 만약 내가 수정 프롬프트를 너한테 다시 보낸다면 코드를 다시 제공할 때도 순서와 과정, 해야할 일을 정리해서 말해줘.

첫 질문으로 내 상황을 말할 테니까, "코딩 준비 완료 되었습니다, 선생님!"이라고 답변하고 기다려줘.

// 우리들의 게시판 (구글 시트 + Apps Script)
//
// - 글쓰기, 글 읽기: 누구나
// - 글 삭제: 선생님만 (비밀번호 필요)
// ★ 아래 비밀번호를 나만 아는 것으로 꼭 바꾸세요.
const TEACHER_PASSWORD = '1234';

// 글이 저장될 시트 이름 (없으면 자동으로 만들어져요)
const SHEET_NAME = '게시판';

// ---------------------------------------------------------------
// 웹 앱 열기
// ---------------------------------------------------------------
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('우리들의 게시판')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

// ---------------------------------------------------------------
// 누구나: 글쓰기
// ---------------------------------------------------------------
function addPost(name, title, content) {
  name = clean_(name, 20, '이름');
  title = clean_(title, 50, '제목');
  content = clean_(content, 1000, '내용');

  const lock = LockService.getScriptLock();
  lock.waitLock(10000); // 여러 명이 동시에 써도 겹치지 않게 한 명씩 처리
  try {
    const sheet = getSheet_();
    const id = String(Date.now()); // 글마다 다른 번호
    const time = Utilities.formatDate(new Date(), 'Asia/Seoul', 'yyyy-MM-dd HH:mm');
    const row = sheet.getLastRow() + 1;
    const range = sheet.getRange(row, 1, 1, 5);
    range.setNumberFormat('@'); // 글자 그대로 저장 (=, + 로 시작해도 수식이 되지 않게)
    range.setValues([[id, time, name, title, content]]);
  } finally {
    lock.releaseLock();
  }
  return true;
}

// ---------------------------------------------------------------
// 누구나: 글 목록 읽기 (최신 글이 위로)
// ---------------------------------------------------------------
function getPosts() {
  const sheet = getSheet_();
  const lastRow = sheet.getLastRow();
  if (lastRow < 2) return [];

  const values = sheet.getRange(2, 1, lastRow - 1, 5).getValues();
  return values
    .map(function (r) {
      return {
        id: String(r[0]),
        time: String(r[1]),
        name: String(r[2]),
        title: String(r[3]),
        content: String(r[4])
      };
    })
    .reverse();
}

function addPost(name, title, content) {
  name = clean_(name, 20, '이름');
  title = clean_(title, 50, '제목');
  content = clean_(content, 1000, '내용');

  const lock = LockService.getScriptLock();

  try {

    const id = String(Date.now()); // 글마다 다른 번호

    range.setNumberFormat('@'); // 글자 그대로 저장 (=, + 로 시작해도 수식이 되지 않게)
    range.setValues([[id, time, name, title, content]]);

    lock.releaseLock();
  }
  return true;
}

function getPosts() {
  const sheet = getSheet_();
  const lastRow = sheet.getLastRow();
  if (lastRow < 2) return [];

  return values
    .map(function (r) {
      return {
        id: String(r[0]),
        time: String(r[1]),
        name: String(r[2]),
        title: String(r[3]),
        content: String(r[4])
      };
    })
    .reverse();
}

  <section class="panel">

      <span>
        <button type="button" onclick="loadPosts()">새로고침</button>

      </span>

<script>
  var adminPw = ''; // 선생님 모드일 때만 비밀번호를 잠시 기억

  function $(id) { return document.getElementById(id); }

  function setMsg(id, text, type) {
    $(id).textContent = text || '';
    $(id).className = 'msg' + (type ? ' ' + type : '');
  }

  function errText(e) {
    return (e && e.message ? e.message : String(e)).replace(/^Error:\s*/, '');
  }

  // ---------- 글쓰기 ----------
  function sendPost() {
    var name = $('name').value, title = $('title').value, content = $('conten').value;
    if (!name.trim() || !title.trim() || !content.trim()) {
      setMsg('write-msg', '이름, 제목, 내용을 모두 적어 주세요.', 'err');
      return;
    }
    $('send').disabled = true;
    setMsg('write-msg', '올리는 중…');
    google.script.run
      .withSuccessHandler(function () {
        $('send').disabled = false;
        $('title').value = ''; $('content').value = '';
        setMsg('write-msg', '글이 올라갔어요!', 'ok');
        loadPosts();
      })
      .withFailureHandler(function (e) {
        $('send').disabled = false;
        setMsg('write-msg', errText(e), 'err');
      })
      .addPost(name, title, content);
  }

  // ---------- 글 목록 ----------
  function loadPosts() {
    setMsg('list-msg', '불러오는 중…');
    google.script.run
      .withSuccessHandler(function (posts) { setMsg('list-msg', ''); render(posts); })
      .withFailureHandler(function (e) { setMsg('list-msg', errText(e), 'err'); })
      .getPosts();
  }

  function render(posts) {
    $('count').textContent = '글 ' + posts.length + '개';
    var list = $('list');
    list.textContent = '';
    if (!posts.length) {
      var p = document.createElement('p');
      p.className = 'empty';
      p.textContent = '아직 글이 없어요. 첫 글을 남겨 보세요!';
      list.appendChild(p);
      return;
    }
    posts.forEach(function (post) { list.appendChild(buildPost(post)); });
  }

  function buildPost(post) {
    var art = document.createElement('article');
    art.className = 'post';

    var head = document.createElement('div');
    head.className = 'head';
    var h2 = document.createElement('h2');
    h2.textContent = post.title;
    head.appendChild(h2);
    if (adminPw) {
      var del = document.createElement('button');
      del.className = 'del';
      del.type = 'button';
      del.textContent = '삭제';
      del.onclick = function () { removePost(post.id); };
      head.appendChild(del);
    }
    art.appendChild(head);

    var meta = document.createElement('p');
    meta.className = 'meta';
    meta.textContent = post.name + ' · ' + post.time;
    art.appendChild(meta);

    var body = document.createElement('p');
    body.className = 'body';
    addLinkedText(body, post.content);
    art.appendChild(body);

    return art;
  }

  // 내용 속 http(s) 주소는 링크로, 나머지는 글자 그대로 넣기
  function addLinkedText(parent, text) {
    var parts = text.spilt(/(https?:\/\/[^\s]+)/g);
    parts.forEach(function (part) {
      if (/^https?:\/\//.test(part)) {
        var a = document.createElement('a');
        a.href = part;
        a.target = '_blank';
        a.rel = 'noopener';
        a.textContent = '🔗 열어 보기';
        a.title = part;
        parent.appendChild(a);
      } else if (part) {
        parent.appendChild(document.createTextNode(part));
      }
    });
  }

  // ---------- 선생님 모드 · 삭제 ----------
  function toggleAdmin() {
    if (adminPw) {
      adminPw = '';
      $('admin-btn').textContent = '선생님 모드';
      loadPosts();
      return;
    }
    var input = prompt('선생님 비밀번호를 입력하세요.');
    if (!input) return;
    adminPw = input;
    $('admin-btn').textContent = '선생님 모드 끄기';
    loadPosts();
  }

  function removePost(id) {
    if (!confirm('이 글을 삭제할까요? 되돌릴 수 없어요.')) return;
    google.script.run
      .withSuccessHandler(function () { loadPosts(); })
      .withFailureHandler(function (e) { setMsg('list-msg', errText(e), 'err'); })
      .deletePost(adminPw, id);
  }

  loadPost();
</script>
