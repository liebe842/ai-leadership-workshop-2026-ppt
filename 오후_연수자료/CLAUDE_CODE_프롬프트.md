교사 직무연수 오후 세션(3시간)에 쓸 **웹 슬라이드 HTML**을 만들어 줘.

## 참고할 것
1. **구조 템플릿**: https://shk-cell.github.io/2026-Colombia/apps-script-intro.html
   - 한 파일짜리 웹 슬라이드, 이전/다음 버튼과 키보드(←, →) 넘기기, 화면 모드(라이트/다크) 전환
   - 파트 구분 슬라이드(큰 번호), 3~4칸 카드, 번호 붙은 단계 안내, 파일명·줄 수·복사 버튼이 있는 코드 블록, 완성본 미리보기 링크
   - 이 구조와 기능은 그대로 따르되, **언어는 한국어만** 써 줘 (스페인어 병기 없음).
2. **디자인**: `/design-sync`로 가져온 디자인 시스템의 색·글꼴·간격·모서리 토큰을 적용해 줘. 템플릿의 색은 쓰지 말고 디자인 시스템을 우선해.
3. **내용**: `afternoon/오후_슬라이드_구성안.md`의 슬라이드 1~44를 순서대로 모두 만들어 줘. 표에 적힌 내용을 빠짐없이 넣고, 문장은 슬라이드에 맞게 짧게 다듬어도 돼.
4. **코드·프롬프트 원문**: 아래 파일 내용을 슬라이드에 **한 글자도 바꾸지 말고** 복사 버튼이 있는 블록으로 넣어 줘.
   - 슬라이드 18 역할 프롬프트, 19 게시판 요청서 예시, 30 수정 요청 예시, 35 빈 요청서 양식 → `afternoon/board/prompts.md`
   - 슬라이드 32 대비용 코드 → `afternoon/board/Code.gs`, `afternoon/board/index.html`
   - 슬라이드 13 정답 비교 → `afternoon/debug/` 의 bug/answer 파일에서 바뀐 한 줄씩

## 만들 파일
- `afternoon/index.html` : 슬라이드 본체 (HTML 한 파일, 외부 라이브러리 없이)
- 슬라이드 9의 미션 파일 다운로드 링크는 `debug/mission1-bug.html`, `debug/mission2-bug.html`, `debug/mission3-bug.html` 로 연결하고, `download` 속성을 붙여 줘. 세 파일을 한 번에 받을 수 있게 `debug/missions.zip`도 만들어 링크해 줘.
- 정답 파일(`*-answer.html`)은 슬라이드에서 링크하지 마. 강사용이야.

## 지켜야 할 것
- 📷 표시가 있는 슬라이드에는 캡처 이미지를 넣을 자리를 만들어 줘. `afternoon/img/슬라이드번호-설명.png` 경로로 `<img>`를 넣고, 이미지가 없을 때는 점선 상자에 "캡처 자리: (설명)"이 보이게 해 줘.
- 완성본 미리보기 URL, 공용 게시판 URL, QR은 아직 없어. `TODO-URL` 같은 표시가 눈에 띄게 남도록 자리만 만들어 줘.
- 코드 블록은 길어도 잘리지 않게 슬라이드 안에서 스크롤되게 해 줘.
- 프로젝터(1280×720)와 노트북 화면 모두에서 글자가 충분히 크게 보이게 해 줘. 한 슬라이드에 너무 많은 내용이 들어가면 슬라이드를 나눠도 되지만, 구성안의 순서는 유지해 줘.
- 각 슬라이드 오른쪽 아래에 슬라이드 번호를 보여 줘.
- 구성안의 **강사 메모**는 슬라이드에 보이지 않게 하고, 키보드 `N`을 누르면 열리는 발표자 메모 패널에 넣어 줘.

## 작업 순서
1. 템플릿 페이지와 구성안을 읽고, 슬라이드 목록(번호·제목·레이아웃 유형)을 먼저 보여 줘. 내가 확인하면 만들기 시작해.
2. 파트 5까지 먼저 만들고 멈춰서 보여 줘. 디자인을 확인한 뒤 나머지를 만들게.
3. 다 만든 뒤에는 브라우저에서 열어 모든 슬라이드를 넘겨 보고, 복사 버튼이 원문을 정확히 복사하는지, 다크 모드에서 글자가 잘 보이는지 확인해 줘.
