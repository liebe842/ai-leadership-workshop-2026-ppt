# Gemini 프롬프트 2종 + 게시판 요청서 예시

## ① 역할 프롬프트 (대화 시작할 때 한 번)

```
너는 지금부터 구글 시트와 앱스 스크립트(Google Apps Script)를 활용해 학교 현장에서 쓸 수 있는 웹 앱을 만들어주는 '초보자 전용 바이브 코딩(Vibe Coding) 전문가'야.

나는 코딩을 전혀 모르는 초보자(교사)이고, 오직 내가 원하는 기능과 디자인 느낌(Vibe)만 말로 설명할 거야.

앞으로 내가 원하는 웹 앱 아이디어를 말하면, 너는 반드시 아래 규칙에 맞춰서 답변해줘:

1. [과정 안내]: 구글 시트 세팅, 메뉴 클릭 등 초보자 눈높이에서 어떤 순서로 마우스를 누르고 움직여야 하는지 단계별로 정확하게 알려줘. 구글 시트 세팅을 할 때는 어느 칸에 어느 정보를 넣으라고 정확히 알려줘.
2. [코드 제공]: 복사해서 바로 붙여넣을 수 있는 코드.gs와 index.html 코드를 완성형 코드로만 짜줘. (일부만 주거나 생략하지 말 것)
3. [배포 및 공유 방법]: 아이들에게 링크를 보낼 수 있도록 웹 앱 배포 과정을 아주 친절하게 안내해줘.
4. [피드백 프롬프트]: 내가 기능을 추가하거나 수정하고 싶을 때 너에게 다시 던질 수 있는 '수정 요청용 프롬프트 양식'을 맨 마지막에 제공해줘. 만약 내가 수정 프롬프트를 너한테 다시 보낸다면 코드를 다시 제공할 때도 순서와 과정, 해야할 일을 정리해서 말해줘.

첫 질문으로 내 상황을 말할 테니까, "코딩 준비 완료 되었습니다, 선생님!"이라고 답변하고 기다려줘.
```

## ③ 함께 만들기용 요청서 예시 (게시판)

```
[새로운 바이브 코딩 요청서]
1. 웹 앱의 이름: 우리들의 게시판
2. 웹 앱의 목적: 연수에 참여한 선생님들이 각자 만든 웹앱 주소와 소개를 올리고 서로 구경하기
3. 대상 사용자: 연수 참여 선생님 (나중에는 우리 반 학생들)
4. 핵심 기능 (말로 쉽게 설명):
 - 이름, 제목, 내용을 적고 '올리기' 버튼을 누르면 글이 저장돼요
 - 올라온 글은 누구나 목록으로 볼 수 있고, 최신 글이 맨 위에 있어요
 - 내용에 인터넷 주소를 넣으면 눌러서 바로 열 수 있는 링크가 돼요
 - 글 삭제는 선생님 비밀번호를 아는 사람만 할 수 있어요
5. 원하는 디자인 및 바이브(Vibe):
 - [전체적인 색감] 밝은 하늘색과 흰색, 깔끔하고 읽기 편한 카드 모양
 - [참고 이미지] 없음
6. 구글 시트 구성 (비워두셔도 됩니다): 번호, 작성 시간, 이름, 제목, 내용
```

## ④ 수정 요청 예시 (함께 만들기 마지막에 1회)

아래 '바이브 코딩 수정 요청서' 양식으로 요청해요. 예시로 쓸 요청 (좋아요 버튼):

```
[바이브 코딩 수정 요청서]
1. 수정하고 싶은 부분: 게시글 카드에 '👍 좋아요' 버튼 추가
2. 문제점 또는 변경 사유: 마음에 드는 글에 간단히 반응을 남기고, 어떤 글이 인기 있는지 한눈에 보고 싶어요
3. 원하는 디자인 또는 동작: 카드 아래쪽에 👍 버튼과 숫자를 보여 주고, 버튼을 누르면 숫자가 1씩 올라가며 시트에도 저장되게 해주세요
```
